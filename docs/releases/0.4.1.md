# ibcmd-rs 0.4.1

Исправлены сборка и разбор расширений CFE, а также подготовлены новые
переносимые архивы с исправленной совместимостью Linux.

## Расширения CFE

- `cf bootstrap <XML> <новый.cfe> --platform <версия>` собирает расширение
  непосредственно из полного XML без исходного CFE, базы и установленной
  платформы. `--base-free` использует тот же независимый сборщик.
- Файловый и SQL-разбор используют общий обработчик заимствования. Исправлены
  заимствованные формы, права, стили и шрифты 8.5, свойства типов,
  предопределённые элементы и ряд свойств элементов форм.
- `cf load` сохраняет служебные данные открытых модулей при правке текста.
  Замена закрытого `.bin` исходником `.bsl` создаёт свежий контейнер модуля.
- Читаются native-контейнеры с непустым списком свободных страниц; configinfo
  проверяется по идентичности, полноте строк и SHA-1 упакованных данных.
  Неизвестные данные не маскируются успешным строгим экспортом.
- Устранено влияние сборки base-free на последующие операции в одном процессе.

На трёх расширениях БСП 8.5 (`_ДемоПустоеРасширение`, `_ДемоРасширение`,
`ServiceDesk`) получено побайтовое совпадение XML, BSL и ресурсов: **997/997**
файлов при файловом разборе и **1000/1000** при SQL-выгрузке. Проверены оба
bootstrap, новые Version/BSL и `cf load`: 84 команды, 33 точных сравнения.
Это равенство выгруженных деревьев, а не обещание идентичности всего CFE-файла.
Штатный контроль 8.5.1.1150 запускался с `--threads=1`: его параллельный экспорт
оказался нестабилен даже на одинаковых CFE. Исходная БСП не изменялась.

## Состав накопленных изменений master

После v0.4.0 также включены независимая сборка CF с `--base-free`, дальнейшие
исправления CF/XML и EDT/XML, строгий отказ при непрочитанном содержимом,
проверки физических источников и диагностика управляемых сеансов/кэшей.
Их конкретные возможности и ограничения описаны в [README](../../README.md),
[справочнике команд](../COMMANDS.md) и [границах CFE](../extensions/parity.md).
Наличие этих изменений не означает завершения всех milestone 0.5–0.7.

## Архивы

Выпуск собирается и проверяется для Windows x64, Linux x64/ARM64 и macOS
Intel/ARM64. Linux собирается на Ubuntu 22.04; ABI-аудит отклоняет зависимости
от GLIBC новее **2.35** (исправление #441). Для каждой платформы публикуются
ZIP, его SHA-256 и CycloneDX SBOM. Исторические архивы v0.4.0 не заменяются.

В v0.4.0 у `cf bootstrap` нет ключа `--base-free`; для описанных команд нужен
архив **0.4.1** либо соответствующая сборка исходников.

## Сохраняющиеся ограничения

- SQL 8.5 import/apply/activation расширений (#348) не принят этим файловым
  CFE-прогоном. Исходные SQL-базы в этих проверках использовались только для чтения.
- Не завершены полная трасса ERP УХ для двух структурных сценариев (#336),
  побайтовая приёмка всех производных кэшей (#403) и полная сквозная S1-матрица
  Config/16 `.si` (#407). Эти задачи остаются открытыми и перенесены в 0.5 с
  сохранением исходных критериев. Новое native PASS для них здесь не заявляется.
- Поддержка новых объектов и реструктуризации ограничена опубликованным
  контрактом S1; остальные случаи требуют штатного `config apply`.
