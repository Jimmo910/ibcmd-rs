# Приёмка выпуска 0.4.1

Дата аудита: 21 октября 2026. PR: [#467](https://github.com/Untru/ibcmd-rs/pull/467).
Версия основного пакета уже повышена до 0.4.1 в слитом #454; Cargo.toml и
Cargo.lock согласованы. Зависимости и исторические релизные теги не меняются.

## Замечания review и CI

- Источником служебного frame/info может быть только модуль с `text`.
  Закрытый `image`-контейнер заменяется свежим. Регрессия проверяет упакованные
  байты в module-only и compiled путях `cf load`.
- Одинаковая проверка отсутствующего свойства заимствованного объекта вынесена
  в общий helper; пробелы в ObjectBelonging учитываются.
- Проверяется полнота обратного GUID-реестра относительно forward mapping.
- Удалены тестовые post-processing helpers, которые production уже не вызывает.
- Глобальный BASE_FREE_STAGE удалён: режим передаётся существующим detached
  SqlExec конкретного вызова. Это устраняет три падения полной библиотеки CI,
  не разрешая base-free writer обращаться к базе.
- Обновлён inventory физического policy-guard для изменившихся schema dispatch,
  module info/text, form slots и известных extension property GUIDs из #467.
  Новых исключений из сканирования и изменений самого guard нет; его self-tests
  и EDT corpus governance выполнены. Таблица GUID остаётся неизменной от #467.

Перед публикацией требуется зелёный CI окончательного HEAD PR, затем зелёный
Standalone Release на точном теге. Пять target-сборок проверяют ZIP, checksum,
SBOM и отсутствие platform-oracle; Linux отдельно ограничен GLIBC 2.35.
Лабораторные native-контроли запускаются только на F; исходная bsp — чтение.

## Milestone 0.4

Перечитаны все 32 задачи и их доказательства приёмки. 29 ранее закрытых задач
сохраняют подтверждённую опубликованную область 0.4. Их текущие native-прогоны
не объявляются повторно выполненными этим аудитом; регрессии окончательного
общего HEAD проходят отдельно в CI и release gate.

Три открытые задачи перенесены в 0.5 с комментариями и сохранением критериев:

- [#336](https://github.com/Untru/ibcmd-rs/issues/336): нет двух полных native
  XE-трасс ERP УХ (реквизит / новая база).
- [#403](https://github.com/Untru/ibcmd-rs/issues/403): typed-диагностика слита,
  полная исходная приёмка `.si` и полномочия на вставку ещё не завершены.
- [#407](https://github.com/Untru/ibcmd-rs/issues/407): неполная побайтовая
  Config/16 `.si` приёмка сквозной S1-матрицы.

Это явный перенос незавершённой работы, а не закрытие. Ограничения указаны
в release notes. Исходные native evidence и старые комментарии сохранены.
