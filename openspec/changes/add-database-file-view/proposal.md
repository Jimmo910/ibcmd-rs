# Открытие и сравнение исходников базы

Задача № 383. На основе подключений № 477 и дерева № 379 добавляются
виртуальные файлы `ibcmd-rs:/<база>/<путь>` только для чтения. Данные поступают
через `source/read`; декодирование сохраняет исходные байты UTF-8 и двоичных
макетов. Смена источника отменяет чтение и делает прежние адреса недоступными.

Команда сравнения файла открывает стандартное сравнение VS Code. Для группы
или объекта `objects/status` возвращает изменённые, только местные и только
хранимые в базе файлы; пользователь выбирает файл из списка. Отсутствующая
сторона представлена пустым виртуальным документом. Несохранённые правки
в местном каталоге требуют сохранения до сравнения группы. Отдельный файл
сравнивается с открытым документом редактора, включая несохранённые правки.

Подсветка BSL предоставляется установленным языковым расширением.
Собственного разбора или записи исходников в базу здесь нет.

Проверка ERP УХ менее чем за секунду остаётся отдельным условием приёмки:
на компьютере нет этой базы, файла CF или XML-выгрузки. Задачу автоматически
закрывать нельзя. Малый пример и искусственные задержки не заменяют ERP УХ.
