## ADDED Requirements

### Requirement: Виртуальные файлы базы
Расширение SHALL предоставлять исходники базы как виртуальные файлы только
для чтения и сохранять точные байты, возвращённые сервером.

#### Scenario: Открытие модуля
- **WHEN** пользователь выбирает открытие модуля из подключённой базы
- **THEN** редактор открывает адрес `ibcmd-rs` с текстом штатной выгрузки.

#### Scenario: Попытка записи
- **WHEN** вызывается запись, удаление, переименование или создание каталога
- **THEN** поставщик файлов отказывает, не вызывая изменяющих операций сервера.

#### Scenario: Изменение подключения
- **WHEN** источник меняется при незавершённом чтении
- **THEN** чтение отменяется, а прежний адрес не начинает читать новую базу.

### Requirement: Сравнение с местными файлами
Расширение SHALL открывать стандартное сравнение VS Code для файла и
предоставлять список отличий для объекта или группы.

#### Scenario: Файл только в одной стороне
- **WHEN** выбран файл, существующий только в базе или только в местном каталоге
- **THEN** отсутствующая сторона отображается как пустой документ.

#### Scenario: Несохранённые местные правки
- **WHEN** запрошено сравнение группы с несохранёнными файлами
- **THEN** расширение предлагает сохранить правки до сравнения.
