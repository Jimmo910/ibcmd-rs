# Выполненные проверки

## Исправления по замечаниям №496 от 23 октября 2026 года

- При копировании унаследованного файлового подключения сохраняется `rows-dir`,
  отсутствие сервера не заменяется `localhost`. SQL-аутентификация не запрашивается.
  Проверены записи с сервером и без него, а также чтение сохранённой записи
  настоящим сервером и открытие `Configuration.xml` без учётных данных SQL.
- Повторное получение адреса во время чтения сохраняет запись файла: оба
  потребителя получают одинаковые байты из одного запроса. Смена источника
  по-прежнему отменяет чтение, отсутствующая сторона сравнения остаётся отдельной.
- Для группы запрашивается полный результат `objects/status` с последующим
  отбором по виду и владельцу. Поэтому учитываются целиком местные объекты;
  соседние группы не попадают в результат. Такая проверка группы может требовать
  больше времени на большой базе, поскольку сервер сравнивает всю конфигурацию.
- `npm test` с настоящим сервером: 41 проверка, без ошибок и пропусков.
- `npm run format:check`: оформление соответствует Prettier.
- `npm run test:source-host`: успешный запуск в настоящем VS Code. Проверены
  изменённый модуль, отдельный местный файл, целиком местный объект с модулем,
  исключение объекта соседней группы и прежние проверки чтения и сравнения.
