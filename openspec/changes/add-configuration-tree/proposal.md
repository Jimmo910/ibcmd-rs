# Дерево конфигурации в редакторе

Задача № 379: показать состав базы или XML-выгрузки в отдельном дереве VS Code.
Основа подключений поступает из запроса № 477. Представление версий из № 484
остаётся отдельным; идентификатор нового представления — `ibcmd.configuration`.

Уровни читаются по мере раскрытия. Описания объектов нужны для вложенных
реквизитов, табличных частей и синонимов; принадлежащие файлы предоставляет
существующий `source/read`, дополненный полем `files`.

Поиск по всему дереву намеренно читает описания ещё не раскрытых объектов.
Обновление дерева и смена подключения сбрасывают его кэш. Изменения местных
XML/BSL в рабочей области также сбрасывают местное дерево.

Полная приёмка требует замера ERP УХ: раскрытие группы до двух секунд,
повторное раскрытие из кэша и соответствие состава полной выгрузке.
ERP УХ на текущем компьютере отсутствует; проверки небольшого сохранённого
примера не заменяют этот замер. Задача остаётся открытой до полной приёмки.
