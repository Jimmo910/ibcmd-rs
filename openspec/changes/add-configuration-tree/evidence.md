## Исправления по замечаниям №495 от 23 октября 2026 года

- Посторонние пространства имён в XML пропускаются до разбора имени и вида
  дочернего объекта. Проверены сохранённые примеры 2.17, 2.20 и 2.21:
  реквизиты, табличные части и поиск остаются доступны. Одноимённые посторонние
  элементы не подменяют свойства метаданных; неизвестные коллекции основного
  пространства имён по-прежнему отклоняются.
- Отмена поиска передаётся текущему чтению. Совместное раскрытие узла продолжает
  работать; после отмены последнего потребителя чтение отменяется и допускает
  повтор. Запоздалый ответ не вытесняет новый результат из кэша.
- `npm test` с настоящим `target/debug/ibcmd-rs.exe`: 30 проверок,
  без ошибок и пропусков.
