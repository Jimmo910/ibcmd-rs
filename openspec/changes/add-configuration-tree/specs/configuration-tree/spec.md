## ADDED Requirements

### Requirement: Чтение дерева по уровням
Расширение SHALL показывать отдельное дерево конфигурации из базы либо XML,
читать уровни при раскрытии и повторно использовать результат до обновления.

#### Scenario: Повторное раскрытие группы
- **WHEN** пользователь повторно раскрывает ранее прочитанную группу
- **THEN** расширение использует кэш без нового запроса к серверу.

#### Scenario: Смена источника
- **WHEN** источник изменяется во время чтения
- **THEN** предыдущий ответ не изменяет новое дерево.

### Requirement: Полный просмотр и переход
Расширение SHALL показывать вложенные объекты, реквизиты, табличные части
и принадлежащие файлы, искать имя и синоним, открывать местный файл.

#### Scenario: Вложенные реквизиты
- **WHEN** раскрыта табличная часть
- **THEN** её реквизиты доступны только для просмотра.

#### Scenario: Поиск синонима
- **WHEN** введён фрагмент синонима объекта
- **THEN** результат позволяет перейти к соответствующему узлу дерева.
